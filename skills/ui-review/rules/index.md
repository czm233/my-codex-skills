# 规则索引

表单含辅助说明、图片加工、保存反馈、运行状态或多阶段操作时，同时加载 [表单个人基线](personal-forms.md)：UI-BASELINE-010（说明层级）、011（图片分组）、012（同行保存反馈）、013（清单原因）、014（阶段分离与草稿保留）。来源为2026-10-05用户反馈；不计功能分，证据边界见各条，最终视觉待人工确认。

按适用条件组合加载，不按语言只选一个文件。

| 文件 | 加载条件 | 内容 |
| --- | --- | --- |
| [common.md](common.md) | 所有 UI | 通用交互初始检查基线 |
| [personal-baseline.md](personal-baseline.md) | 所有 UI，逐条核对适用条件 | 组件复用、信息呈现、输入框聚焦、手机标题与对齐、导航精简等个人基线，单独报告 |
| [platforms/web.md](platforms/web.md) | Web UI（浏览器或桌面 Web 视图） | Web 布局与分批加载规则；验证范围以各条记录为准 |

common.md 与 personal-baseline.md 的 001 条目是 2026-09-28 建立的初始检查基线，不是用户历史案例，不据此声称覆盖 React、Vue、SwiftUI 等框架特有问题。common.md 的 UI-COMMON-004、platforms/web.md 的 UI-WEB-001 至 UI-WEB-005、personal-baseline.md 的 UI-BASELINE-002 与 UI-BASELINE-003 来自 2026-09-28 / 2026-10-02 实测案例。今后按实际案例继续增加 platforms/、frameworks/、libraries/ 文件并更新此表。

UI-BASELINE-004 来自 2026-10-05 的输入框双边框实测记录，属于个人基线，不计功能分；鼠标与键盘聚焦均需验证。

这些条目不把指定色板、奖牌画法、固定两项底栏或每批 20 条提升为所有项目的要求；已确认的个人基线不计功能分。记录规则不是对当前页面出具通过报告，应用时仍按检查流程验证。

UI-BASELINE-009：同类控件变更须覆盖全部适用入口，见 [个人工程基线](personal-baseline.md)。来自 2026-10-05 下拉控件统一案例；个人基线不计功能分，源码覆盖、自动化及部分浏览器验证分别记录，未实测入口不得视为通过。
